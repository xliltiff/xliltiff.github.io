My goal is to build a better understanding of foundation for networking, cloud computing, and security as I work on my self-guided preparation for a future degree in information security.

## 📖 Currently learning

### 1. 🔐 Introduction to Cybersecurity
- **Platform:** Cisco Networking Academy, The Open University
- **Foundational knowledge learned:**
  - Understanding of cybersecurity principles and terminology
  - Awareness for cybersecurity threats such as malware, phishing, social engineering
  - The basics of network security and firewalls
  - Knowledge of ethical and legal considerations in cybersecurity
  - How broad cybersecurity careers and pathways are
 
### ☁️ AWS Certified Cloud Practitioner
- **Platform:** AWS skills builder
- **Skills to understand:**
  - Understanding of cloud computing concepts and AWS global infrastructure
  - Basics of cloud architecture design principles
  - Gain understanding to the introduction of billing, pricing models, and the AWS Free Tier
  - Awareness for security and compliance in cloud environments
  - Get familiarised with shared responsibility model and cloud support plans
  - Knowledge for core for AWS services (EC2, S3, RDS, Lambda, IAM)

### 🛠️ CompTIA A+ (Core 1 & 2)
- **Platform:** Professor Messer, CertMaster Learn
- **Currently exploring:**
  - Core 1 (200-1101)
    - Introduction to computer hardwares and mobile devices
    - Installation and configuration of laptops, printers, and peripherals
    - Basic networking concepts and troubleshooting
    - Virtualisation, cloud computing, and internet protocols
  - Core 2 (200-1102)
    - Installation and support of operating systems (Windows, macOS, Linux, mobile OS)
    - Security best practices for devices and networks
    - Software troubleshooting and diagnostic tools
    - Understanding of operational procedures, documentation, and professionalism in IT
   
### 🧠 CompTIA Security+ (SYO-701)
- **Platform:** Professer Messer, TryHackMe
- Threats, Vulnerabilities & Attack
- Cryptography
- Incident responses
- Risks managements

### 🌐 Cisco Certified Network Associate (CCNA)
- **Platform:** Cisco NetAcad, FreeCodeCamp CCNA 8 hour video (Youtube), Jeremy's IT lab (Youtube)
- **Currently Exploring:**
  - **The fundamentals of Networking**
    - OSI and TCP/IP models
    - IPv4 and IPv6 addressing & subnetting
    - Different types of networks : LAN, WAN, WLAN, VLAN
    - Network topologies and hardwares
  -**Routing and Switching**
    - Cisco router and switch configuration
    - Routing protocols: RIP, OSPF, EIGRP basics
    - VLAN setup and inter-VLAN routing
    - Spamming Tree Protocol (STP) for redundancy
  - **IP connectivity**
    - Static and dynamic routing concepts
    - Default gateway configuration
    - Network Address Transaltion (NAT)
  -**Security Fundamentals**
    - Firewalls, VPNs and Access Control Lists (ACLs)
    - Device Hardening techniques
    - Basic threat identification and mitigation
  -**Infrastructure Services**
    - DCHP, DNS and network management protocols (SCMP, Syslog)
    - Introduction to Quality of Services (QoS)
  -**Infrastructure Automation & Programmability**
    - Basics of network automation and APIs
    - Software-Defined Networking (SDN) overview
  -**Troubleshooting**
    - Diagnosing and resolving network connectivity issues
    - Using Cisco's IOS commands for troubleshooting
