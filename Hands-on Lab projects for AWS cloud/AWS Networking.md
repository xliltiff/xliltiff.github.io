# 🌐 AWS Networking and Content Delivery

## ⚡️ Lab Title:  "Explore Amazon VPC, Route 53 and CloudFront"

---

## 🎯 Objectives
- To understand how AWS handles networking and content delivery
- Exploring key services: Amazon VPC, Route 53 and CloudFront
- Learn to observe and understand basic configurations

---

## Instrution guide

### ♦️Exploring Default VPC
1.Search and open **VPC** in the console
2. Under "Your VPCs", locate **default VPC**
Click to view details such as CIDR block and subnets

### ♦️Investigating Internet gateway
1. In console, search for **Internet gateways**
2. Check if an internet gatewat is attached to default VPC
3. Click on gateway ID to view attachment details

### ♦️ Exploring Route 53 (DNS service)
1. Open **Route 53**
2. Click on **Hosted Zones**
3. Optionally, click **Create Hosted Zone** and stop at configuration screen

---

### ♦️Review Cloudfront Distributions
1. Locate *CloudFront** from the console
2. Check if there are existing distributions
3. Click **Create Distribution** and review default settings like origin domain, caching behaviour
