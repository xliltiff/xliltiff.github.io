# AWS Storage and Databases

## ⚡️Lab Title: "Exploring S3, EBS and RDS via Console provided by AWS"

---

## 🎯 Objectives
- Understanding AWS main sorage services
- Navigate, create and review storage and data base services provided on AWS console
- Complete all instruction guides with Ipad-friendlly AWS console interface without CLI

  ---

  ## 🗒️Instructions

  ### ♦️ Creating an S3 Bucket
  1. A bucket of Amazon S3 should be created from previous [Hands-On lab (Computing cloud)](https://github.com/xliltiff/xliltiff.github.io/blob/main/Hands-on%20Lab%20projects%20for%20AWS%20cloud/Cloud%20computing.md)
  2. Upon entering a bucket name, a region should be selected
  3. Click into the bucket to review its properties and permissions
 
  ---

  ### ♦️ Review EBS volumes
  1. Search and open **EC2** from the Console
  2. In the sidebar, navigate the **Elastic Block Store > Volumes**
  3. View the list of EBS volume
  4. Optionally, click **Create Volume** to preview the setup

  ---

  ### ♦️ Explore Amazon RDS
  1. Search and open **RDS** in the console
  2. Click **Databases** to see if any are created
  3. Click **Create database** and review engine options like MySQL, PostgreSQL, etc
  4. Do not launch - just review configuration steps
